# CoinFlow

Coin Flow — лендінг-сервіс «планувальник денного бюджету». Користувач за хвилину отримує безпечний денний ліміт витрат, без реєстрації й без стресу.

**Демо:** https://coin-flow-lab6.netlify.app/

## Можливості

- **Симулятор безпечного ліміту.** Три повзунки (дохід, обов'язкові витрати, заощадження) і формула
  `ліміт = (дохід − витрати − заощадження) / 30` з округленням вниз.
- **Сценарії накопичення:** агресивний (70 %), збалансований (50 %), консервативний (30 %) від вільних коштів.
- **Діаграма накопичення**, збереження результату у PDF (друк), посилання зі збереженим станом симулятора.
- **Форми** раннього доступу та розсилки з валідацією email.
- **Сторінка з ембеддингом** (`embed.html`): карта Google Maps, відео YouTube та нативне відео, інформер курсу валют НБУ.
- **Сторінки** «Прайс» і «Документація».
- Адаптивна верстка (mobile-first), семантична розмітка, доступність (WCAG 2.2 AA).

## Технології

HTML5 · Tailwind CSS v4 · ванільний JavaScript · Netlify / GitHub Pages

## Структура проєкту

```
├── index.html            головна сторінка (лендінг)
├── embed.html            вбудований контент: карта, відео, інформер
├── pricing.html          прайс
├── docs.html             документація
├── css/
│   ├── tailwind.css      зібраний Tailwind (генерується)
│   └── style.css         власні стилі (симулятор, FAQ, ефекти Hero)
├── assets/
│   ├── images/           логотип, відео
│   ├── icons/            SVG-іконки
│   └── js/               site.js, simulator.js, rates.js
├── src/input.css         вхідний файл Tailwind (токени дизайн-системи)
├── scripts/              build-pages.js, prepare-deploy.js
├── components/           окремі Tailwind-компоненти (пісочниця)
└── DESIGN-SYSTEM.md      відповідність токенів Figma класам Tailwind
```

## Запуск і розробка

```bash
npm install            # встановити залежності
npm run watch:css      # стежити за змінами й перезбирати css/tailwind.css
npm run build:css      # одноразова мінімізована збірка CSS
npm run build:pages    # згенерувати pricing.html, docs.html, embed.html
```

Для перегляду відкрийте `index.html` у браузері або запустіть розширення Live Server у VS Code.

## Публікація

- **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)`.
- **Netlify:** імпорт репозиторію з GitHub, команда збірки порожня, папка публікації `/`.
